# Aayush Shrestha - Portfolio

Personal portfolio website showcasing AI Agent development work, built with React and Vite.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React Icons

## Running the app

```bash
npm install
npm run dev
```

## Building for production

```bash
npm run build
npm run preview
```

## Features

- Dark minimal design with subtle amber accents
- Smooth scroll animations
- Responsive layout
- Sections: Hero, Featured Work, Experience, About, Skills, Contact
